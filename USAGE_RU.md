## Как это работает

Мод подключается к стандартному генератору карт Rust через Harmony и меняет его параметры на лету. Карта остаётся «процедурной», но вы управляете дорогами, реками, монументами, биомами и т.д.

> ⚠️ **Мод только для генерации карт.** После того как карта сгенерирована и сохранена, мод рендерит превью и **закрывает сервер**. Не оставляйте `CustomGenerator.dll` в `HarmonyMods` на рабочем сервере: он будет генерировать карту и выключаться, а скрипт с авто-рестартом зациклится.
>
> Обычный порядок такой: сгенерировать `.map` на отдельной копии сервера, затем поставить её на рабочий сервер через `server.levelurl` или локальный `server.level`.

## Установка

1. Нужен Rust Dedicated Server. Harmony 2.3 в нём уже есть.
2. Скопируйте `CustomGenerator.dll` в `<папка сервера>/HarmonyMods/`.
3. Готово. Конфиг создастся при первом запуске.

Где что лежит (все пути относительно папки сервера, где находится `RustDedicated.exe`):

| Путь | Что там |
|---|---|
| `HarmonyMods/CustomGenerator.dll` | Сам мод |
| `HarmonyConfig/CustomGenerator.json` | Конфиг |
| `HarmonyConfig/CustomGenerator.schema.json` | Схема конфига для подсказок в редакторе (создаётся сама, не редактируйте) |
| `HarmonyConfig/logs/cgen_*.log` | Логи мода, по файлу на запуск |
| `maps/` | Сгенерированные карты (`.map`) |
| `maps/prefabs/` | Ваши монументы для свапа |
| `mapimages/` | Превью карт (`.png`) |
| `mapimages/resources/` | Шрифты для превью (скачиваются сами) |

## Первый запуск и генерация

1. Запустите сервер с нужными `+server.worldsize` и `+server.seed`:
   ```bat
   RustDedicated.exe -batchmode -nographics +server.identity gen +server.worldsize 4000 +server.seed 12345 +server.level "Procedural Map"
   ```
2. Мод создаст `HarmonyConfig/CustomGenerator.json`, сгенерирует карту по стандартным настройкам и выключит сервер.
3. Отредактируйте конфиг и запустите сервер снова. Каждый запуск даёт новую карту.
4. Результат появится в `maps/CustomGenerator<размер>_<сид>.map`, превью в `mapimages/`.

Генерация карты 4000 занимает около 5–10 минут, рендер превью ещё около минуты.

> Сид и размер задаются параметрами запуска сервера, а не конфигом мода.

## Конфиг: общее

### Язык
Первое поле конфига:
```json
"Language (en/ru)": "ru"
```
Для нового конфига язык берётся из языка системы. Ключи понимаются на **обоих** языках: поменяйте значение на `en` или `ru`, перезапустите сервер, и файл перепишется с ключами на выбранном языке. Все значения сохранятся.

Ниже ключи приведены на английском, в скобках русский вариант.

### Подсказки в редакторе
Рядом с конфигом мод пишет `CustomGenerator.schema.json`, а первая строка конфига ссылается на него (`"$schema"`). Откройте конфиг в **VS Code** (или другом редакторе с поддержкой JSON Schema), и вы получите:
- описание каждой настройки при наведении, на языке конфига;
- автодополнение ключей и допустимых значений (биомы, текстуры, топологии, `HeightMode`, `distanceSame` и т.д.);
- подчёркивание ошибок: опечатка в биоме, отрицательное расстояние, текст вместо числа.

Схема перезаписывается при каждом запуске, поэтому всегда соответствует вашей версии мода. Не редактируйте её и не удаляйте строку `"$schema"`.

### Версия и обновления
Поле `"Version"` не трогайте. При обновлении мода:
- старый конфиг копируется в `CustomGenerator.json.<старая версия>.backup`;
- новые настройки дописываются со значениями по умолчанию, ваши значения остаются.

### Если в конфиге ошибка
- **Сломан JSON** (лишняя запятая, незакрытая скобка): файл сохраняется как `CustomGenerator.json.broken-<дата>`, а мод запускается со стандартным конфигом. Исправьте ошибку в копии и верните её на место.
- **Недопустимое значение** (отрицательный процент, неизвестный биом в фильтре и т.п.): в лог пишется `[WARN]` с объяснением, и значение заменяется безопасным **только на этот запуск**, файл не меняется. После запуска всегда просматривайте предупреждения в `HarmonyConfig/logs`.

Мод перечитывает и пересохраняет конфиг при каждом запуске, поэтому форматирование файла может поменяться. Это нормально.

## Настройки карты — `Map Settings`

(`Настройки Карты`)

| Ключ | По умолч. | Описание |
|---|---|---|
| `Generate new map everytime` | `true` | Не загружать уже сгенерированную карту с диска, а каждый раз генерировать заново |
| `Override Map Sizes (9000 not be changed to 6000)` | `true` | Разрешить размеры меньше 1000 и больше 6000. Без этого Rust обрезает размер |
| `Override Map Folder (saves to <Server Root>/maps/)` | `true` | Сохранять карту в `<папка сервера>/maps/` |
| `Override Map Name` | `true` | Задавать имя файла карты по шаблону ниже |
| `Map Name ({0} - size, {1} - seed)` | `CustomGenerator{0}_{1}` | Шаблон имени: `{0}` — размер, `{1}` — сид. `.map` дописывается сам |

> ⚠️ Не генерируйте карты **больше 6000**. Клиент Rust их не поддерживает: он покажет карту 6000, а монументы и префабы будут висеть в воздухе.

В имени карты допустимы только `{0}` и `{1}`. Если указать, например, `{2}`, мод вернёт шаблон по умолчанию и напишет предупреждение.

## Основной генератор — `Main Generator`

(`Основной Генератор`)

### Дороги и рельсы — `Road`, `Rail`

```json
"Road": {
  "ShouldChange": true,
  "Enabled": true,
  "GenerateRing": true,
  "GenerateSideMonuments": true,
  "GenerateSideObjects": false
}
```

| Ключ | Описание |
|---|---|
| `ShouldChange` | Главный выключатель блока. При `false` всё остальное игнорируется, дороги генерируются как в ванильной игре |
| `Enabled` | Кольцевая дорога (ЖД). `false` — кольца не будет на любом размере |
| `GenerateRing` | Кольцо на **любом** размере карты. В ванильной игре кольцо появляется только на больших картах |
| `GenerateSideMonuments` | Придорожные (прирельсовые) монументы: заправки, супермаркеты, станции и т.п. |
| `GenerateSideObjects` | **Только `Road`.** Придорожные объекты. При `false` они не генерируются совсем. У `Rail` это поле ни на что не влияет |

> `Enabled` и `GenerateRing` управляют именно **кольцом**. Обычные дороги между монументами генерируются всегда.

### Уникальное окружение — `UniqueEnviroment`

```json
"UniqueEnviroment": {
  "ShouldChange": true,
  "GenerateOasis": true,
  "GenerateCanyons": true,
  "GenerateLakes": true
}
```
При `ShouldChange: true` оазисы, каньоны и озёра включаются (`true`) или выключаются (`false`) **на любом размере карты**. В ванильной игре они есть только на картах от 4000–4500. Болота джунглей этим блоком не управляются, они настраиваются в [монументах](#монументы--monuments) (`unique_environment/jungle`).

### Реки, ЛЭП, туннели, прочее

| Ключ (EN) | Ключ (RU) | По умолч. | Описание |
|---|---|---|---|
| `Remove Rivers` | `Удалить реки` | `false` | Карта без рек |
| `River width scale (1 = default)` | `Множитель ширины рек (1 = по умолчанию)` | `1` | Ширина рек: `0.7` — уже, `1.5` — шире. Должно быть больше 0 |
| `Remove Car Wrecks around Road` | `Удалить разбитые префабы машин около дороги` | `false` | Убрать разбитые машины вдоль дорог |
| `Allow building on road` | `Разрешить строительство на дорогах` | `false` | Разрешить строиться на дорогах: мод убирает с них запрет на строительство |
| `Remove large powerlines` | `Удалить большие ЛЭП` | `false` | Карта без больших ЛЭП |
| `Remove tunnel entrances` | `Удалить входы в туннели` | `false` | Убрать входы в подземку. Сами туннели остаются |
| `Remove underground tunnels (also removes entrances)` | `Удалить подземные туннели (вместе со входами)` | `false` | Убрать подземку целиком вместе со входами |

### Тиры и биомы — `Change percentages`

```json
"Change percentages": true,
"Tier Percentages (100 in total)": { "Tier0": 30, "Tier1": 30, "Tier2": 40 },
"Biome Percentages (Arid+Temperate+Tundra+Arctic = 100, Jungle is separate)": {
  "Arid": 40, "Temperate": 15, "Tundra": 15, "Arctic": 30, "Jungle": 50
}
```

- Проценты применяются только при `"Change percentages": true`.
- **Тиры** (зоны сложности лута, от Tier0 у края карты до Tier2 в глубине): в сумме 100. Если сумма другая, значения пересчитываются пропорционально, например 1/1/2 = 25/25/50.
- **Биомы**: `Arid` (пустыня), `Temperate` (умеренный), `Tundra`, `Arctic` в сумме дают 100. Иначе они тоже пересчитываются пропорционально.
- **`Jungle` в сумму не входит.** Это отдельный параметр от 0 до 100. В ванильной игре он равен 50.
- Отрицательные значения или нулевая сумма считаются ошибкой. Тогда остаются ванильные проценты, а в лог пишется предупреждение.

В примере выше указаны ванильные значения, от них удобно отталкиваться.

## Монументы — `Monuments`

(`Монументы`)

### Как получить список
Мод сам заполняет `MonumentList` при каждом запуске, независимо от `Enabled`.
1. Запустите генерацию один раз. В `MonumentList` появятся все группы монументов из игры (сейчас их 18) с ванильными настройками.
2. Поставьте `"Enabled": true` и меняйте нужные группы. Остальные не трогайте: у них `"ShouldChange": false`, и они работают как в ванильной игре.

После обновления Rust новые группы добавляются сами (в логе будет `Added N monument groups to the config`), а изменённые вами группы не трогаются. Группа, которой больше нет в игре, остаётся в списке с предупреждением в логе — удалите её вручную. Чтобы вернуть группе ванильные значения, удалите её из списка: при следующем запуске она добавится заново.

### Группы
Каждая запись — это **группа** монументов, а не отдельный монумент. Группа соответствует папке префабов в игре.

> ⚠️ Эти «папки» находятся **внутри бандлов игры** (`Bundles/`), а не на диске. Полный путь выглядит как `assets/bundled/prefabs/autospawn/<Folder>/`, например `assets/bundled/prefabs/autospawn/monument/harbor/harbor_1.prefab`. В папке сервера такой папки нет: её нельзя открыть, и положить туда свои префабы тоже нельзя. Значения `Folder` и `OverrideFolder` — это пути внутри бандла. Свои монументы добавляются через [кастомные монументы](#кастомные-монументы--custom-monuments) или [свап](#замена-монументов-свап--swap-monuments).

| `Folder` | `Description` | Что это |
|---|---|---|
| `monument/xlarge,monument/large,monument/medium,monument/small` | Main Monuments | Основные монументы: Launch Site, Airfield, Military Tunnel, Power Plant… |
| `monument/harbor` | Harbors | Харборы и паромный терминал |
| `monument/fishing_village` | Fishing Villages | Рыбацкие деревни |
| `monument/lighthouse` | Lighthouses | Маяки |
| `monument/military_bases` | Desert Military | Военные базы в пустыне |
| `monument/arctic_bases` | Arctic Bases | Арктическая база |
| `monument/tiny` | Tiny Monuments | Мелкие монументы |
| `monument/cave` | Caves | Пещеры |
| `monument/swamp` | Swamps | Болота |
| `monument/ice_lakes` | Ice Lakes | Ледяные озёра |
| `monument/jungle_ruins` | Jungle Ruins | Руины в джунглях |
| `monument/underwater_lab` | Underwater Labs | Подводные лаборатории |
| `tunnel-entrance` | Tunnel Entrances | Входы в подземку |
| `mountain` | Mountains | Горы |
| `unique_environment/...` | Canyons, Lakes, Oasis, Jungle Swamps | Уникальное окружение |

Список взят с текущей версии Rust и может меняться. Актуальный список всегда в вашем `MonumentList` после автоопределения.

### Поля группы

```json
{
  "ShouldChange": true,
  "Generate": true,
  "Description": "Harbors",
  "Folder": "monument/harbor",
  "MinWorldSize": 0,
  "TargetCount": 5,
  "distanceSame": "Max",
  "MinDistanceSameType": 300,
  "distanceDifferent": "Any",
  "MinDistanceDifferentType": 50,
  "Filter": { "Enabled": true, "...": "..." },
  "OverrideFolder": "",
  "IncludePrefabs": ["harbor"],
  "ExcludePrefabs": [],
  "PrefabCopies": { "harbor": 5 },
  "IgnoreWorldSizeMultiplier": true
}
```

**Основные**

| Поле | Описание |
|---|---|
| `ShouldChange` | `true` — применить настройки ниже. `false` — группа работает как в ванильной игре, остальные поля игнорируются |
| `Generate` | `false` — группа не генерируется вообще (например, без маяков). Работает только при `ShouldChange: true` |
| `Description`, `Folder` | Название группы и её путь в бандле. По `Folder` мод находит группу, **не меняйте его**. Сменить папку можно через `OverrideFolder` |
| `MinWorldSize` | Минимальный размер карты, с которого группа появляется. `0` — на любом |
| `TargetCount` | Сколько монументов группы поставить. `0` — «все префабы группы», как в ванильной игре. Итоговое число может оказаться меньше, если не хватает места (см. дистанции) |

**Дистанции**

| Поле | Описание |
|---|---|
| `MinDistanceSameType` | Минимальное расстояние (м) до монументов **этой же** группы |
| `MinDistanceDifferentType` | Минимальное расстояние (м) до монументов **других** групп |
| `distanceSame` / `distanceDifferent` | Предпочтение при выборе места: `Max` — подальше, `Min` — поближе, `Any` — без разницы |

Если монументы не помещаются, игра сама постепенно ослабляет минимальные дистанции, вплоть до четверти от заданных. Поэтому большие дистанции не гарантируют, что меньшего расстояния не будет, а только делают его менее вероятным.

**Фильтр места — `Filter`**

Определяет, где монумент может стоять.

```json
"Filter": {
  "Enabled": true,
  "SplatType": ["Grass", "Forest"],
  "BiomeType": ["Temperate"],
  "TopologyAny": [],
  "TopologyAll": [],
  "TopologyNot": ["River", "Road"]
}
```

| Поле | Смысл | Пустой список |
|---|---|---|
| `Enabled` | `true` — заменить ванильный фильтр группы этим | — |
| `SplatType` | Разрешённые типы поверхности | любая |
| `BiomeType` | Разрешённые биомы | любой |
| `TopologyAny` | Нужна **хотя бы одна** из топологий | любая |
| `TopologyAll` | Нужны **все** перечисленные топологии | без условия |
| `TopologyNot` | **Ни одной** из перечисленных | без условия |

Допустимые значения:
- **SplatType:** `Dirt`, `Snow`, `Sand`, `Rock`, `Grass`, `Forest`, `Stones`, `Gravel`
- **BiomeType:** `Arid`, `Temperate`, `Tundra`, `Arctic`, `Jungle` и другие
- **Topology:** `Field`, `Cliff`, `Summit`, `Beachside`, `Beach`, `Forest`, `Forestside`, `Ocean`, `Oceanside`, `Decor`, `Monument`, `Road`, `Roadside`, `Swamp`, `River`, `Riverside`, `Lake`, `Lakeside`, `Offshore`, `Rail`, `Railside`, `Building`, `Cliffside`, `Mountain`, `Clutter`, `Alt`, `Tier0`, `Tier1`, `Tier2`, `Mainland`, `Hilltop`

Названия чувствительны к регистру. Опечатку мод отбросит, а в лог выведет полный список допустимых значений. После автоопределения у групп уже заполнен ванильный фильтр, его удобно брать за основу.

> Фильтр только ограничивает место. Если сделать его слишком строгим (например, `Arctic` + `Beach`), монументов может не получиться совсем.

**Выбор префабов**

Это поля для управления тем, *какие именно* монументы группы попадут на карту.

| Поле | Описание |
|---|---|
| `OverrideFolder` | Другой путь **внутри бандла** вместо ванильного, относительно `assets/bundled/prefabs/autospawn/`. Указывать можно только пути, которые есть в игре, например `Folder` другой группы. Несколько путей через запятую: `"monument/harbor,monument/lighthouse"`. Пусто — ванильный путь |
| `IncludePrefabs` | Оставить только префабы, в имени которых есть одна из строк. Пусто — все |
| `ExcludePrefabs` | Убрать префабы, в имени которых есть одна из строк |
| `PrefabCopies` | `"часть имени": N` — сколько копий префаба положить в пул кандидатов. `0` — ни одной |
| `IgnoreWorldSizeMultiplier` | В ванильной игре `TargetCount` дополнительно умножается на коэффициент по размеру карты, и этот коэффициент задан только до 6000. `true` — ставить ровно `TargetCount` |

Как это работает:
- Правила сравниваются с **именем префаба без папки**, регистр не важен. `"harbor"` подходит к `harbor_1` и `harbor_2`, но не к `ferry_terminal_1`, хотя тот лежит в `monument/harbor`.
- Обычно каждый префаб группы встречается на карте **один раз**. Поэтому, чтобы получить 5 харборов при двух вариантах харбора, нужны **копии**: `PrefabCopies: {"harbor": 5}` плюс `TargetCount: 5`.
- Имена префабов, которые можно указать, есть в логе. Для каждой группы с правилами мод пишет строку вида
  ```
  Harbors: '.../monument/harbor' 3 -> 10 candidates (available: ferry_terminal_1, harbor_1, harbor_2)
  ```
  Чтобы узнать имена в группе, поставьте ей любое правило (например, `"ExcludePrefabs": ["nothing"]`) и запустите генерацию.

> Монументы расставляются по группам по очереди. Если резко увеличить одну группу (например, харборов), следующим может не хватить места, и часть основных монументов пропадёт. В таком случае уменьшите дистанции или увеличьте размер карты.

## Кастомные монументы — `Custom Monuments`

`Custom Monuments` (`Кастомные Монументы`)

Добавляет на карту ваши монументы, сделанные в RustEdit, как **новые** монументы вместе с их рельефом. Свободные места для них мод находит сам во время генерации. Ванильные монументы при этом не заменяются: чтобы поставить свой монумент вместо ванильного, используйте [свап](#замена-монументов-свап--swap-monuments).

| | Кастомные монументы | Свап |
|---|---|---|
| Где | Новые места, которые выбирает мод | Ровно там, где стоял ванильный монумент |
| Рельеф | Высоты, текстуры, топология и дыры из вашего файла | Не меняется |
| Дороги и рельсы | Строятся с учётом монумента (он ставится раньше них) | Строились под оригинал |
| Когда | Во время генерации | После сохранения карты |

### Настройки

```json
"Custom Monuments": {
  "Enabled": true,
  "Folder with .map files (relative to server root)": "maps/custom",
  "List": [
    {
      "Enabled": true,
      "Name": "Заправка",
      "File": "gas_station.prefab",
      "Count": 2,
      "Radius": 0,
      "Blend": 25,
      "HeightMode": "Stamp",
      "CopySplat": true,
      "CopyTopology": false,
      "CopyAlpha": true,
      "RandomRotation": true,
      "MaxHeightDifference": 15,
      "MinHeight": 2,
      "MaxHeight": 150,
      "MinDistanceToMonuments": 150,
      "MinDistanceSameType": 500,
      "Filter": { "Enabled": false }
    }
  ]
}
```

`Enabled` (`Включить`) включает весь раздел, папка (`Папка с .map файлами`) — где лежат ваши файлы, по умолчанию `maps/custom`. Каждая запись в `List` (`Список`) — один файл монумента.

### Подготовка файла

Поддерживаются два формата. Положите файл в папку и впишите его имя в `File`.

**`.map`** — обычная карта RustEdit с вашим монументом.
- **Первый префаб** в иерархии — якорь, центр монумента. Поставьте туда SpawnPoint (или префаб оригинального монумента), как для [свапа](#шаг-1-сделайте-монумент-в-rustedit). Якорь-SpawnPoint на карту не ставится. `.map`, сделанный для свапа, подойдёт и здесь.
- Позиции префабов берутся относительно якоря, высоты — относительно земли под якорем.
- Рельеф (высоты, текстуры, топология, дыры) читается с карты вокруг якоря, так что делайте рельеф прямо там.

**`.prefab`** — «Save as prefab» в RustEdit.
- Точка (0, 0, 0) — центр, `y = 0` — уровень земли.
- Если RustEdit сохранил рельеф рядом с префабом (`<имя>.prefab.heights`, `.splat0`, `.splat1`, `.alpha`, `.topology`), держите эти файлы рядом с `.prefab`, и они будут использованы. Без них ставятся только префабы, а `Stamp` работает как `Flatten`.

Префабы, которых нет в текущей версии Rust, и префабы со сломанными координатами (NaN) пропускаются с предупреждением в логе.

### Поля

| Поле | По умолчанию | Описание |
|---|---|---|
| `Enabled` | `true` | Размещать этот монумент. Если файла нет, запись отключается с предупреждением |
| `Name` | `""` | Имя для лога и превью карты. Пусто — имя файла |
| `File` | `""` | Имя файла в папке кастомных монументов |
| `Count` | `1` | Сколько копий разместить. Может встать меньше, если не хватит места |
| `Radius` | `0` | Радиус площадки (м). `0` — автоматически: самый дальний префаб + 10 м, минимум 20 м |
| `Blend` | `25` | Ширина (м) кольца вокруг площадки, где рельеф монумента плавно переходит в рельеф мира |
| `HeightMode` | `Stamp` | `Stamp` — высоты из файла. `Flatten` — ровная площадка. `None` — оставить рельеф мира |
| `CopySplat` | `false` | Копировать текстуры земли из файла |
| `CopyTopology` | `false` | Копировать топологию из файла (тиры остаются от мира) |
| `CopyAlpha` | `true` | Копировать дыры в рельефе, например входы в бункеры |
| `RandomRotation` | `true` | Поворачивать каждую копию случайно вокруг вертикальной оси |
| `MaxHeightDifference` | `15` | Макс. перепад высот (м) рельефа мира под площадкой |
| `MinHeight` / `MaxHeight` | `2` / `150` | Допустимая высота рельефа (м над уровнем моря) в центре |
| `MinDistanceToMonuments` | `150` | Мин. расстояние (м) до других монументов |
| `MinDistanceSameType` | `500` | Мин. расстояние (м) между копиями этого монумента |
| `Filter` | выкл. | Где может стоять монумент, как [фильтр группы](#поля-группы) |

### Как происходит размещение
1. Кастомные монументы ставятся сразу после основных ванильных монументов, **до дорог и рельсов**. Площадка получает топологию `Monument`, поэтому дороги, рельсы, скалы и декор её обходят.
2. Мод перебирает случайные места и из первых 16 подходящих выбирает самое ровное. Места зависят от сида: один и тот же сид даёт один и тот же результат.
3. Место подходит, если:
   - высота рельефа в центре между `MinHeight` и `MaxHeight`, и `Filter` разрешает центр (`TopologyNot` проверяется по всей площадке);
   - площадка на суше, без океана, рек, озёр, дорог, рельсов и других монументов, а кольцо `Blend` не задевает океан, реку или монумент;
   - перепад высот под площадкой не больше `MaxHeightDifference`;
   - до ванильных монументов не меньше `MinDistanceToMonuments` + `Radius`, и площадка не пересекается с другими кастомными (между копиями одной записи — `MinDistanceSameType`).
4. Рельеф внутри `Radius` задаётся по `HeightMode` относительно средней высоты площадки и плавно сводится с миром в пределах `Blend`.
5. Записи обрабатываются по порядку списка, поэтому первым достаются лучшие места.

В логе видна каждая поставленная копия и итог:
```
Custom monument 'Заправка' #1: 312, -845 (height 24.3, rotation 117)
Custom monument 'Заправка': placed 2/2, radius 46m, 118 prefabs each
```

## Замена монументов (свап) — `Swap Monuments`

(`Замена Монументов`)

Свап подменяет ванильные монументы на карте вашими версиями из `.map`-файлов, сделанных в RustEdit. Место, поворот, дороги и рельсы остаются от оригинала.

### Настройки

```json
"Swap Monuments": {
  "Enabled": true,
  "Save both maps (with swap and without)": true
}
```

| Ключ | Описание |
|---|---|
| `Enabled` (`Включить`) | Включить свап |
| `Save both maps (with swap and without)` (`Сохранить обе карты (с заменой и без)`) | `true` — оригинал остаётся как `<имя>.map`, а версия со свапом сохраняется как `<имя>.swapped.map`. `false` — оригинал **перезаписывается** версией со свапом |

### Как работает свап
Свап выполняется **после** генерации, когда карта уже сохранена:
1. Мод открывает сохранённую карту `maps/<имя>.map`.
2. Для каждого файла `maps/prefabs/<имя>.map` ищет на карте монументы, в пути которых встречается `<имя>`.
3. Удаляет найденный монумент и ставит на его место все префабы из вашего файла: позиция и поворот берутся у оригинала, остальные префабы ставятся относительно первого объекта файла.
4. Сохраняет результат (см. `Save both maps`).

Что **не** переносится:
- рельеф, текстуры и топология из вашего `.map`. Берутся только **префабы**, земля под монументом остаётся ванильной;
- дороги и рельсы: они остаются подключёнными к старому монументу;
- превью в `mapimages/`: оно строится до свапа и показывает **оригинальные** монументы.

### Шаг 1. Сделайте монумент в RustEdit

**Вариант А — монумент на основе оригинала** (добавляете объекты к ванильному монументу):
1. Поставьте оригинальный монумент **без поворота** (0, 0, 0). Удобнее всего в точку (0, 0, 0), но позиция не важна: всё считается относительно него.
2. Добавьте свои объекты вокруг.
3. Оригинальный монумент должен быть **первым объектом в иерархии**.

**Вариант Б — полностью кастомный монумент** (без оригинала):
1. Поставьте **SpawnPoint** в **(0, 0, 0)** без поворота и сделайте его **первым в иерархии**. Он обозначает **центр оригинального монумента**, на место которого встанет ваш.
2. Стройте монумент относительно этой точки.
3. Учтите, что центр ванильного монумента не всегда совпадает с его визуальным центром. Например, у заправки центр находится ниже постройки из-за пещеры под ней, поэтому кастомную заправку надо поднять, иначе она уйдёт под землю. Примеры есть в `Examples/prefabs/full_custom_monuments/`.

При свапе SpawnPoint заменяется служебным префабом с нулевым размером и на карте не виден.

Готовые шаблоны лежат в папке `CustomPrefabs/` (спасибо FlySelf), примеры — в `Examples/prefabs/`.

### Шаг 2. Назовите файл правильно

```
<имя ванильного префаба>.prefab.map
```
Примеры: `harbor_1.prefab.map`, `fishing_village_c.prefab.map`, `gas_station_1.prefab.map`.

- Мод отрезает `.map` и ищет **`harbor_1.prefab`** в путях монументов.
- **Не пропускайте `.prefab`.** Файл `harbor_1.map` тоже сработает, но будет искать просто `harbor_1` и может зацепить лишнее.
- Имя ванильного префаба можно узнать в RustEdit или в логе монументов (поле `available`, см. [Выбор префабов](#поля-группы)).

### Шаг 3. Положите файл

```
<папка сервера>/maps/prefabs/harbor_1.prefab.map
```
Папка создаётся сама при первом свапе. Файлов может быть сколько угодно: каждый заменит **все** подходящие монументы на карте.

### Шаг 4. Сгенерируйте карту
Запустите генерацию. В логе сервера появятся строки `[SWAP MN]`. Проверьте результат, открыв `.swapped.map` (или `.map`) в RustEdit.

### Свап и настройки монументов вместе
Их можно совмещать. Например, сделать 3 харбора через `PrefabCopies` и заменить все `harbor_1` своей версией: свап заменит **каждый** экземпляр.

## Готовые рецепты

**Маленькая карта с кольцом дорог и ЖД, без рек**
```json
"Road": { "ShouldChange": true, "Enabled": true, "GenerateRing": true, "GenerateSideMonuments": true, "GenerateSideObjects": true },
"Rail": { "ShouldChange": true, "Enabled": true, "GenerateRing": true, "GenerateSideMonuments": true, "GenerateSideObjects": false },
"Remove Rivers": true
```

**Больше снега, меньше пустыни**
```json
"Change percentages": true,
"Biome Percentages (Arid+Temperate+Tundra+Arctic = 100, Jungle is separate)": { "Arid": 15, "Temperate": 25, "Tundra": 20, "Arctic": 40, "Jungle": 30 }
```

**5 харборов, без паромного терминала** (группа `monument/harbor`)
```json
"ShouldChange": true, "Generate": true, "TargetCount": 5, "MinDistanceSameType": 300,
"IncludePrefabs": ["harbor"], "PrefabCopies": { "harbor": 5 }, "IgnoreWorldSizeMultiplier": true
```

**Только одна рыбацкая деревня определённого типа** (группа `monument/fishing_village`)
```json
"ShouldChange": true, "Generate": true, "TargetCount": 1, "IncludePrefabs": ["fishing_village_c"]
```

**Карта без маяков** (группа `monument/lighthouse`)
```json
"ShouldChange": true, "Generate": false
```

**Без подземки и ЛЭП**
```json
"Remove underground tunnels (also removes entrances)": true,
"Remove large powerlines": true
```

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Сервер выключается после старта | Так и задумано: мод генерирует карту и выключает сервер. Уберите `CustomGenerator.dll` из `HarmonyMods`, если нужен обычный сервер |
| Настройка не применяется | `ShouldChange: true` в нужном блоке или группе? Нет ли предупреждений `[WARN]` в `HarmonyConfig/logs`? |
| Конфиг «сбросился» | Скорее всего, был сломан JSON. Ищите `CustomGenerator.json.broken-*` рядом |
| Монументов меньше, чем `TargetCount` | Не хватает места: уменьшите `MinDistance*`, ослабьте `Filter`, увеличьте карту. Для дублей нужны `PrefabCopies` |
| Пропали другие монументы | Одна группа заняла место. Уменьшите её или дистанции |
| Не знаю имя префаба | Поставьте группе любое правило и посмотрите строку `available:` в логе |
| Свап не сработал | Файл лежит в `maps/prefabs/`? Имя вида `<префаб>.prefab.map`? `Swap Monuments → Enabled: true`? Нет ли ошибок `Swap:` в логе? |
| Свапнутый монумент сдвинут, повёрнут или ушёл в землю | Первый в иерархии оригинал или SpawnPoint? Он без поворота? SpawnPoint соответствует центру оригинала (с учётом высоты)? |
| Кастомный монумент не поставился | Ищите в логе `no suitable spot found`: уменьшите дистанции, увеличьте `MaxHeightDifference`, расширьте `MinHeight`–`MaxHeight`, ослабьте `Filter`, возьмите карту больше. Ошибки файла тоже пишутся в лог |
| Кастомный монумент висит в воздухе или ушёл в землю | `.map`: якорь (первый префаб) стоит на земле? `.prefab`: `y = 0` — это уровень земли? Попробуйте `"HeightMode": "Flatten"` |
| На превью старые монументы | Нормально: превью строится до свапа. Проверяйте результат в RustEdit |
| Нет превью или ошибка шрифтов | Нет интернета: скопируйте шрифты из папки `Resources/` репозитория в `mapimages/resources/` |
| Карта больше 6000 выглядит сломанной | Клиент Rust не поддерживает такие размеры, используйте не больше 6000 |

По вопросам поддержки обращайтесь в [наш дискорд](https://discord.gg/xUdpkm8RUS).
